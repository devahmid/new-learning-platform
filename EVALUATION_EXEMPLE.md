# Exemple d'évaluation - Format complet

Ce document montre comment créer une évaluation avec le format demandé, incluant les sections et les instructions détaillées.

## Structure de l'évaluation

### Titre
```
📋 Évaluation classes ( A )
```

### Description
```
Assalāmou ʿalaykoum wa raḥmatou Llāh,
Bienvenue dans ce formulaire d'évaluation qui porte sur la matière suivante :
👉 Arabe Niveau 1
```

### Instructions détaillées
```
🧠 Cette évaluation a pour objectif de vérifier ce que tu as compris et retenu depuis le début de l'année. 

✅ Conseils avant de commencer :
- Lis chaque question avec attention.
- Réponds seul(e) et sincèrement, pour évaluer ton propre niveau.
- Si une question te semble difficile, passe à la suivante et reviens-y ensuite.
- Clique sur "Suivant" pour passer à la section suivante.

Les questions avec rédaction doivent être faites sur feuille.
Prends une photo claire de ta feuille et envoie-la à :
📧 arabedevoirs@gmail.com
📝 Objet du mail : Prénom – Classe ( A )

Tu as tout le week-end pour répondre.
🕒 Prends ton temps, et fais de ton mieux !
📚 Qu'Allah facilite ta compréhension et te compte parmi les gens du savoir, āmīn.
```

### Instructions spéciales
```
Les questions avec rédaction doivent être faites sur feuille.
Prends une photo claire de ta feuille et envoie-la à :
📧 arabedevoirs@gmail.com
📝 Objet du mail : Prénom – Classe ( A )
```

## Sections

### Section 1 : CROYANCE (ʿAQĪDA)

**Titre de la section :**
```
Section CROYANCE (ʿAQĪDA)
```

**Description de la section :**
```
📘 Croyance (ʿAqīda)

Cette partie évalue ta compréhension de la croyance musulmane.
Lis bien chaque question, prends le temps de réfléchir et réponds avec sincérité.

Souviens-toi : la croyance est la base de notre religion et le lien qui nous unit à Allah.

Qu'Allah te facilite.
```

### Questions de la section

**Question 1 :**
- **Type :** Choix multiple (radio)
- **Texte :** "Combien de questions fondamentales le musulman doit-il connaître ?"
- **Obligatoire :** Oui
- **Options :**
  1. 2
  2. 5
  3. 4
  4. 6
  5. 3

## Guide de création dans l'interface admin

1. **Créer l'évaluation :**
   - Titre : `📋 Évaluation classes ( A )`
   - Description : `Assalāmou ʿalaykoum wa raḥmatou Llāh, Bienvenue dans ce formulaire d'évaluation qui porte sur la matière suivante : 👉 Arabe Niveau 1`

2. **Ajouter les instructions détaillées :**
   - Copiez le texte complet des instructions dans le champ "Instructions détaillées"
   - Vous pouvez utiliser des emojis et du formatage HTML basique

3. **Ajouter les instructions spéciales :**
   - Copiez les instructions spéciales dans le champ dédié

4. **Créer la section :**
   - Cliquez sur "+ Ajouter une section"
   - Titre : `Section CROYANCE (ʿAQĪDA)`
   - Description : Le texte de description de la section

5. **Ajouter les questions :**
   - Cliquez sur "+ Ajouter une question"
   - Sélectionnez la section créée dans le menu déroulant
   - Type : Choix unique (Radio)
   - Texte : "Combien de questions fondamentales le musulman doit-il connaître ?"
   - Marquer comme obligatoire
   - Ajouter les 5 options de réponse

6. **Sauvegarder :**
   - Cliquez sur "Créer" pour sauvegarder l'évaluation

## Formatage HTML dans les instructions

Vous pouvez utiliser du HTML basique dans les instructions détaillées :

- **Gras :** `<strong>texte</strong>`
- **Italique :** `<em>texte</em>`
- **Listes :** `<ul><li>item</li></ul>`
- **Paragraphes :** `<p>texte</p>`
- **Emojis :** Directement dans le texte (📋, 👉, 🧠, etc.)

## Notes importantes

- Les sections permettent d'organiser les questions par thème
- Les instructions détaillées sont affichées en haut de l'évaluation
- Les instructions spéciales sont mises en évidence dans une boîte jaune
- Les questions peuvent être associées à une section ou rester sans section
- L'ordre des sections et des questions peut être réorganisé avec les flèches ↑ ↓
