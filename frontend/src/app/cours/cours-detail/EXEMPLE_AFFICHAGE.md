# Exemples d'affichage dynamique par sous-catégorie

## 1. Cours Arabe avec sous-catégories "Lecture" et "Écriture"

```
┌─────────────────────────────────────────────────────────────┐
│  [Lecture]           [Écriture]                            │
│  - Lire un texte     - Écrire les lettres                 │
│  - Compréhension     - Calligraphie                       │
└─────────────────────────────────────────────────────────────┘
```

## 2. Cours Fiqh avec sous-catégories "Prière" et "Jeûne"

```
┌─────────────────────────────────────────────────────────────┐
│  [Prière]            [Jeûne]                               │
│  - Les ablutions     - Règles du jeûne                     │
│  - Les prières       - Exceptions                          │
└─────────────────────────────────────────────────────────────┘
```

## 3. Cours Croyance avec sous-catégories "Tawhid" et "Prophètes"

```
┌─────────────────────────────────────────────────────────────┐
│  [Tawhid]            [Prophètes]                           │
│  - L'unicité         - Les messagers                       │
│  - Les attributs     - Leurs histoires                     │
└─────────────────────────────────────────────────────────────┘
```

## 4. Cours avec leçons sans sous-catégorie

```
┌─────────────────────────────────────────────────────────────┐
│  [Introduction]      [Conclusion]                          │
│  - Présentation      - Récapitulatif                       │
│  - Objectifs         - Évaluation                          │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                    [Leçons générales]                      │
│  - Leçon bonus  - Révision générale                       │
└─────────────────────────────────────────────────────────────┘
```

## Logique de tri

1. **Leçons avec sous-catégorie** → Affichées dans des sections colorées avec le nom de la sous-catégorie
2. **Leçons sans sous-catégorie** → Affichées dans "Leçons générales" en bas
3. **Couleurs et icônes** → Adaptées selon le type de sous-catégorie
4. **Layout responsive** → 1-3 colonnes selon la taille d'écran
